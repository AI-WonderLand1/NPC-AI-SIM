# AAA Character Asset Requirements

NPC-AI-SIM's final showcase library must use original or properly licensed production assets. Development demo models and avatar generators remain fallbacks only.

For each production character asset, track:

- source / creator
- license
- redistribution rights
- GLB/GLTF path
- triangle count
- material count
- texture resolutions
- PBR maps present
- skeleton / rig
- animation clips
- facial blendshapes or morph targets
- LOD availability
- thumbnail render
- tested quality tier

Minimum showcase animation set:

- Idle
- Walk
- Run
- Turn left/right
- Jump / land
- Talk / gesture

Recommended material support:

- base color / albedo
- normal
- roughness
- metallic where appropriate
- occlusion
- emissive where appropriate

Do not call a character AAA-ready while its primary presentation still depends on generic demo models, DiceBear avatars, primitive geometry, or unverified remote third-party assets.
