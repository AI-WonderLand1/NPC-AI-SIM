# AAA Quality Pass 1

This pass starts the measurable AAA-quality track without replacing the existing NPC runtime architecture or the current visual source of truth.

Implemented:

- cinematic viewport HUD integrated with the real selected NPC
- system Training Lab status remains visible and read-only
- runtime/PBR/status information layered over both WebGL and software-preview paths
- explicit production asset requirements so demo models cannot quietly become the final showcase
- visual QA checklist for desktop editor resolutions

Not claimed complete:

- final AAA character art
- final production animation set
- final pixel match against the master AI Wonderland NPC Behavior Studio image
- final behavior graph/inspector visual polish
- full Training & Skills UI
- WonderPlay handoff

The acceptance bar is defined in `AAA_QUALITY_STANDARD.md`.
